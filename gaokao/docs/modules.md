# 功能模块

逐模块说明**用户看到什么、怎么交互、边界在哪**。实现细节见
[implementation.md](implementation.md)。

---

## 1. 倒计时

倒计时**只有一处**：左栏的 Hero。这是硬约定 ——
曾经为某个阶段另建过一张卡片，同时在数同一件事，页面上并排出现两个
一模一样的倒计时（实测都是 `205 天 11 时 38 分 03 秒`），已删除。

### 三层层级

| 层 | 位置 | 内容 |
| --- | --- | --- |
| 总倒计时 | 左栏 Hero | 目标日期行 → **大天数** → 次级精确行（时分秒）→ 状态条 |
| 当前考试进程 | 右栏首卡 | 下一场/当前场名称、时段、剩余、进度条 |
| 逐场倒计时 | 右栏日程卡 | 9 场考试各自的精确倒计时 |

### 数字字号

天数用**容器查询**按卡片自身宽度缩放（`calc(var(--n) * 1cqw)`），
不随视口宽度 —— 避免在窄卡片里溢出。三档字号系数 `--n` = 22 / 24 / 26。

**数字绝不折行**：容器与文字都写了 `white-space: nowrap`
（`flex-wrap: nowrap` 管不住文字折行）。

### 状态条（pill）

Hero 下方三枚状态，按选定科动态生成：

| 场景 | 内容 |
| --- | --- |
| 高考阶段 | `备考中/高考进行中/已完成` + `下一场 <科目> · N 天后` + `已完成 x / 9 场` |
| 非高考阶段 | `即将开始/进行中/已结束` + `距<下一阶段> N 天` |

> **曾经的坑**：出现过 `下一场 undefined · 246 天后` ——
> 因为 `examDates` 里只有 `{start, end}` 没有 `name`，要回 `exams` 按下标取。
>
> 也**刻意不输出**「共 5 个阶段」这类 pill：那是实现细节，对考生没有信息量。

## 2. 阶段（零诊 / 一诊 / 二诊 / 三诊 / 高考）

### 轨道形态

全宽的一条**路径**，不是卡片里的 tab：

- 页眉左侧「考试阶段」+ 右侧状态文案（`#railMode`）
- 5 个**旋转 45° 的菱形节点**，节点间有连接线
- 露营主题下轨道铺纯 CSS 地图网格纹理

### 节点四态

| 状态 | 样式 |
| --- | --- |
| 已结束 | 实心灰菱形，节点名降噪 |
| 进行中 | 强调色实心 + 光晕 |
| 当前（下一个未结束） | 强调色描边 + 弱光晕，节点名用强调色 |
| 未来 | 白底 + 描边 |

**「当前」的定义是「下一个尚未结束的阶段」，不是「正在查看的那个」。**
零诊已结束、一诊未开始时，考生正要面对的是一诊，因此显示「当前：一诊」。
早期实现取「正在查看的阶段」，默认查看高考时就写「当前：高考」，
与旁边的「距高考还有 246 天」自相矛盾。

### 查看历史阶段

- 点任一节点即切换到该阶段
- **正在查看的阶段 ≠ 当前阶段**时，出现「↩ 回到当前阶段」按钮
  （与它是过去还是未来无关 —— 未来阶段同样需要明确退路）
- 查看**已结束**阶段时轨道边框换成强调色，文案变「查看中：零诊（已结束）」
- 未来阶段**不**换色：未来不是历史，换色会误导

### 关于「连接线断断续续」

**这是刻意的**：每段线只画在「上一个节点到本节点」之间，
两端都让开菱形本体，形成一条**穿过节点**的路径，而不是压过节点的实线。

几何要求：线右端止于菱形中心，相邻两段线在菱形最宽处相接。
菱形视觉半宽约 `3.18px`，让位量取 `--dot * 0.82` ≈ 9px。
若觉得断感明显，把 `--dot` 调小即可让缝隙收窄。

### 关于「倒计时数到哪个阶段」

**选哪个节点就数到那个节点。**

唯一例外是**查看一个已结束的阶段时**：过去的时间没有倒计时可言，
此时箭头指向**下一个尚未开始的阶段**，并且标签、日期行都同步指向它 ——
不会出现「选了零诊、日期行却写着一诊」的错位。

### 切换阶段时的显隐

| 元素 | 高考阶段 | 非高考阶段 |
| --- | --- | --- |
| Hero | 距高考还有 | 距该阶段还有（含阶段全名 + 状态徽章） |
| `#gaokaoContent`（当前考试 + 选科） | 显示 | **隐藏** |
| `#scheduleCard`（考试日程） | 显示 | **隐藏**（它装的是 9 场高考科目） |
| `#calCard`（日历） | 显示 | **显示**（假期与哪个阶段无关） |

> `#scheduleCard` 曾在 v2.3.0 被移出 `#gaokaoContent`，
> 而切换逻辑只隐藏后者，于是切到「一诊」时左栏已是诊断倒计时、
> 右栏却还挂着 9 场高考日程 —— 一屏两套考试。已修复。

### 阶段详情并入 Hero

阶段全名与状态徽章写在 Hero 内部（`#heroPhaseLine`），
**不再另建带倒计时的卡片**。

## 3. 选科标记

### 规则

| 组 | 选项 | 上限 |
| --- | --- | --- |
| 首选 | 历史 / 物理 | 1（互斥单选） |
| 再选 | 化学 / 地理 / 思想政治 / 生物学 | 2 |

### 效果

- **已选**科目的考试卡：左侧竖条变强调色、科名变强调色、附「已选」徽章
- **未选**的选考科目：整体淡化（`opacity: .4`）、附「未选」徽章
- 未做任何选择时：全部科目正常显示，不淡化

实现上用 `isExamRelevant(ex, selectedSubjects)` 作为唯一判据。

> **曾经的坑**：上限判定写成 `sameGroup.length >= max` 且在 push **之前**求值，
> 于是永远晚一步，允许超出「再选 2 科」。

选科结果存入 `localStorage`，刷新后保留。

## 4. 节假日日历

### 三处呈现（同一份数据）

| 位置 | 内容 |
| --- | --- |
| 左栏「下一个假期」卡 | 假期名、日期区间、剩余天数、进度方段 |
| 右栏「日历 · 节假日」卡 | 当月月历 + 月份标签 + 图例 + 当月清单 |
| 弹窗「未来假期速览」 | 下一个假期 + 后续 6 个假期的时间线 |

三处由 `renderHoliday()` **一次写入**，不存在两套数据或同步问题。
弹窗与常驻卡**分工不同**：月历回答「这个月怎么放」，弹窗回答「接下来还有哪些假」。

### 月历格四态

| 状态 | 样式 |
| --- | --- |
| 法定放假 | 整格实色 + 放大圆角（8px，与周围方格的刻意反差） |
| 调休上班 | 45° 斜纹 |
| 今天 | 2px 描边 + 底部方点 |
| 预估（未公布） | 天蓝整格，与「已放假」区分 |

### 月份标签

**连续区间**：从当月起连续 7 个月；若区间内已有假期，
且下一个有安排的月份落在其后 6 个月内，就顺延覆盖它（上限 13 个月）。

> **曾经的坑**：早期是「当月 + 后两月」再补「之后最早有安排的三个月」，
> 而补的那部分**只含有假期的月份** —— 2027 年 2 月春节到 4 月清明之间无假期，
> 3 月被整段跳过，标签变成 `10、11、12、1、2、4`，读起来像「3 月被吃了」。

### 假期段合并

`getHolidayRuns()` 把同名连续放假日合并成段（如「国庆节 10/1–10/7 共 7 天」）。
相邻判定用**整数日序号差 == 1**，不用字符串比较。

> **曾经的坑**：`cnDayKey()` 返回不补零格式（`2026-10-2`），
> 而数据文件用补零格式（`2026-10-02`），字符串比较永远不相等，
> 假期段从不合并。

## 5. 农历与二十四节气

月历每格在日号下方最多再加两行小字：**节气**与**农历**。

| 项 | 样式 |
| --- | --- |
| 节气 | 强调色 + **空心方框**（与图例样例一致） |
| 农历 | 最次级文字色，纯文字 |
| 农历月初 | 显示月名（「腊月」「正月」）而非日名 |
| 相邻月份补格 | 不显示农历与节气 |

实色格（放假 / 预估）上二者自动改走卡片前景色。
读屏的 `aria-label` 补全为「公历 + 农历 + 节气 + 假期」。

### 数据分级

| 年份 | 来源 | 界面显示 |
| --- | --- | --- |
| 2026 / 2027 全年、2028 年 1 月 | 官方表，精确到分 | 节气名（时刻在 `aria-label` 里） |
| 2028 / 2029 | 近似式推算 | 节气名，**不给时刻** |

**为什么不显示时刻**：三行小字里塞不下 `04:02`；且 2028 年以后没有权威时刻，
显示会造成「有的有有的没有」的不一致。时刻保留在 `aria-label` 中供读屏使用。

### 算法验证

已用官方节气表逐条校验：2026 年 24 条农历日期 **24/24 一致**；
2027 全年 + 2028 年 1 月节气名称与时刻 **26/26 一致**，同日农历 **26/26 一致**。
方法见 [testing.md](testing.md)。

## 6. 主题与字号

### 五套主题

| 主题 | 性格 | 强调色 |
| --- | --- | --- |
| 砚台 `ink` | 暖纸 · 人文衬线 | 赭 `#B5722E` |
| 夜航 `night` | 深色主导 | 琥珀 `#F0B357` |
| 白板 `board` | 极简高对比 | 红 `#D0322B` |
| 青瓷 `celadon` | 冷调克制 | 靛青 `#0F6E68` |
| 露营 `camp` | 日落橙 + 天蓝 · 温暖户外 | 橙 `#E8892B` |

**露营主题**对照《摇曳露营△》的视觉语言：背景/边框/文字全落在 H≈30–37° 暖色轴，
唯一冷色是天蓝 H≈195°；实色卡片用橙 / 天蓝 / 草绿 / 沙黄四色。
圆角刻意分三档（2px 标签 / 5px 按钮 / 12px 卡片），**不做「一圆到底」** ——
统一大圆角是机器味的主要来源。全页已无任何全圆角元素，状态点统一为方点。

### 三档字号

`data-size` = `std` / `lg` / `xl`，对应系数 `--n` = 22 / 24 / 26。
与主题**正交**：可以「露营 + 超大」任意组合。

### 三态明暗

`appearance` = `auto` / `light` / `dark`。主题自带明暗身份，
`auto` 模式跟随系统，并记住亮侧调色板（切系统明暗时停留在同一支配色）。

主题菜单是**独立菜单**，不并进设置弹窗。

## 7. 全屏

优先 Fullscreen API；**不可用时退化为同一套覆盖层**，因此 iOS 也能用
（不依赖 iOS 残缺的非视频元素全屏支持）。

显示内容：当前/下一场名称与时段 → **大天数** + 次级精确行 → 进度条 →
底部信息条（下一场 + 进度）。

**大数字带说明行**（`#fsCountLabel`）：`距开考还有` / `距本场结束还有` /
`距全部结束还有`。

> **为什么需要这一行**：大数字数到「下一场开考」，而进度条显示「剩余到结束」，
> 两个数差 21 分钟却没有任何标识，会被读成同一个数。

### 与页面 Hero 的关系

设计上复用同一套数字层级（大天数 + 次级精确行 + 左侧 3px 竖线），
但它们是**独立 DOM**（`.fs-*` / `.hero-countdown`），各自维护。

## 8. 浮动小窗（Picture-in-Picture）

基于 Document Picture-in-Picture API，**仅 Chromium 116+ 支持**。

内容：目标行 → 大天数 + 单位 → 次级精确行 → 下一场。

**配色直接读当前主题的 CSS 变量**，不另写一套写死的值。

> **曾经的坑**：早期判断 `data-theme === 'dark'`（v2.0 的旧主题名），
> v2.1 之后主题名改成 `ink/night/board/celadon/camp`，判断永远为假，
> 于是夜航主题下小窗也是一片浅色。

## 9. 设置（考试日程）

- 弹窗按阶段分节，每节两个日期选择器（开始 / 结束）
- 日期选择器是**自定义日历**，不是原生 `input[type=date]`
- 修改高考日期时，9 场科目时间按北京时间日历天**整体平移**
- 「恢复默认」立即生效，不需要额外保存
- 「取消 / 保存」固定在可视区，只有中间表单滚动

> **曾经的坑**：整卡一起滚动，内容 934px > 可视 798px，
> 「取消 / 保存」被推到折叠线以下，用户看不到按钮。

### 日期选择器的「浏览 ≠ 选中」

`calState` 把「已提交的选中日期」与「浏览中的游标」拆成两组字段。

> **为什么**：早期只有一套字段，`goMonth()` 又把 `day` 重置成 1，
> 于是「只是翻到另一个月」就会把那个月的 1 号画成橙色选中块，
> 误导用户以为已经选了日期。现在翻月不产生任何选中态，
> 翻回原月份则恢复原来的选中。

键盘：`Enter`/`Space`/`方向键` 打开，`方向键` 选日，`Esc` 关闭。

## 10. 骨架屏

绝对定位覆盖内容，加载完成后移除。

**移除有三重保障**：`transitionend` + 兜底定时器 + 强制 `display: none`。

> **为什么**：只依赖 `transitionend` 时，首帧内同时写入 transition 与 opacity
> 可能被浏览器视为终态而不派发事件；标签页在后台、元素未参与绘制、
> 过渡被中断时同样不会派发。结果是骨架屏永久留在 DOM 中盖住正文，
> 表现为**白屏**。

## 11. PWA

`manifest.json` 提供安装能力（图标为内联 data-URI SVG，零外部文件）。
`sw.js` 提供离线缓存。两者都需要 http/https ——
`file://` 下代码有协议守卫，跳过注册并给出 `console.info`，不产生控制台错误。
